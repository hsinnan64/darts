# 飛鏢投擲骨架分析器

用瀏覽器分析飛鏢投擲動作的個人工具。上傳影片後，會即時標出身體骨架與手腕移動軌跡，用來檢視每次出手的動作是否一致。

**線上使用**：https://hsinnan64.github.io/darts/

## 特色

- **影片不會上傳** — 所有運算都在瀏覽器本機完成，影片與分析結果不會傳到任何伺服器
- **免安裝** — 開啟網頁即可使用，手機與電腦都能跑
- **穩定追蹤** — 針對手臂快速揮動時容易跳點的問題做了多層處理

## 功能

| 功能 | 說明 |
|---|---|
| 骨架顯示 | 標出上半身與下半身的關鍵點與連線 |
| 手腕軌跡 | 以紅線畫出投擲手的手腕移動路徑 |
| 投擲手判定 | 自動判斷左右手，只畫實際在動作的那隻手 |
| 純黑背景 | 隱藏影片畫面，只留點、線與軌跡，專注看動作本身 |
| 錄製下載 | 把含骨架與軌跡的畫面錄下來存檔 |

## 使用方式

1. 開啟網頁，等待骨架模型載入完成
2. 點「選擇影片」載入要分析的影片（建議 H.264 編碼的 MP4）
3. 點「播放」開始分析
4. 需要時切換「背景：純黑」或開啟「錄製」

### 拍攝建議

- 側面拍攝，讓投擲手臂完整入鏡不被身體擋住
- 光線充足、背景單純，追蹤會更穩定
- 手機慢動作模式（120fps 以上）能捕捉到更細的出手動作

## 技術架構

純前端單頁應用，無後端、無資料庫、無建置流程。

- **姿態辨識**：[MediaPipe Tasks Vision](https://github.com/google-ai-edge/mediapipe) — `pose_landmarker_full` 模型，GPU 加速
- **繪製**：Canvas 2D
- **錄製**：`canvas.captureStream()` + `MediaRecorder`

### 關於追蹤穩定度

手腕、手肘在快速揮動時動態模糊嚴重，姿態模型輸出的座標容易單幀誤判。程式裡用了幾層處理來壓住這個問題：

1. **離群點拒絕** — 單次偵測位移超過物理上限時，判定為誤判並沿用前一個可信位置
2. **中位數濾波** — 5 幀視窗，吃掉連續誤判造成的尖刺
3. **One Euro Filter** — 時間平滑，手臂關鍵點套用較強的濾波參數
4. **可信度門檻** — 低於門檻的關鍵點不繪製、不納入軌跡，避免亂拉線

另外偵測是**每個影片幀都執行**，不做固定毫秒節流 — 節流會讓偵測慢於畫面更新，中間的幀重複套用舊座標，視覺上就是一停一跳的階梯感。

## 瀏覽器需求

建議使用最新版 Chrome 或 Edge。需要支援 WebAssembly、WebGL 與 `MediaRecorder`。
